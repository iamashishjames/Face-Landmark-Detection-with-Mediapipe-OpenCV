# Face-Landmark-Detection-with-Mediapipe-OpenCV
This project uses MediaPipe Face Mesh and OpenCV to detect 468 3D facial landmarks in real time using a webcam. Each detected landmark is drawn on the face, and can optionally display the full triangular mesh provided by MediaPipe.

Features

Real-time face landmark detection using webcam input
Plots all 468 facial landmarks
Optional face mesh visualization
Lightweight & runs on CPU
Built using MediaPipe’s Face Mesh ML pipeline

Tech Stack

Python
OpenCV
MediaPipe
